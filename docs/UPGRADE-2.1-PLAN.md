# 2.1 audit and implementation plan
Baseline: published 2.0 preview, clean Git HEAD 0a0423a. Baseline build and 11 unit tests passed in 23 seconds.
Architecture retained: Material Views + ViewModel; SQLite JSON records; HTTPS foreground model download service; single-owner llama.cpp runtime; isolated CPU diffusion module.
Confirmed issues: image model selection hard-coded; clearCache skips export subdirectory; chat model deletion can race generation after releasing inference mutex; all conversations fully loaded for list browsing; history redraws decode thumbnails repeatedly; app versions/updates/backups absent; presets lack assistant metadata; network discovery absent; navigation selection can disagree with visible screen; title/button crowding.
Plan: fix correctness first; add bounded library queries, assistant/prompt metadata and safe local backup; introduce Home/Library and organized settings; research and pin additional GGUF choices; add metadata-driven repository discovery and opt-in model revision checks; add trusted GitHub update checks/downloads with checksum, package, signing identity and version verification; keep normal Android installer confirmation; add tests and build a release variant signed for existing-install compatibility. No silent model replacement, unvalidated video, or invented hardware benchmarks.
